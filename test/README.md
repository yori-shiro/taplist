# テスト用データ

動作確認のためのファイル。**アプリの動作には一切関わらない。**
アプリが自分からこれらを読みに行くことはなく、設定画面の「JSONを読み込む」で
明示的に選んだときだけ読み込まれる。

使い方は [TESTING.md](../TESTING.md) を参照。

| ファイル | 用途 |
|---|---|
| `broken.json` | 意図的に壊してあるデータ。正規化が効いているかを確認する（§5） |
| `future-version.json` | `version: 99`。読み込みが拒否されることを確認する（§5） |
| `stale-session.json` | `startedAt` が過去。日付をまたいだときのバナーを確認する（§6） |

**読み込むと現在のデータが置き換わる。** 試す前に「JSONで書き出す」でバックアップを取ること。

中身はすべて架空のデータで、実際の買い物内容は含まない。
