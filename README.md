# かいものリスト

タップだけで運用する買い物リスト。単一のHTMLファイルで動く。

一度アイテムを登録すれば、以降は文字入力なしでリストを作れる。
買い物メモの中身は反復性が高い（牛乳、洗剤、ゴミ袋を年に何十回も打ち込む）ので、
その反復を吸収することを目的にしている。

**メモを取るアプリではなく、入力をゼロにするアプリ。**

---

## できること

- アイテムを一度登録すると、以降はタップで買い物リストに出し入れできる
- 優先度3段階（すぐ買う / ついでに / 機会があれば）
- カテゴリ分け。カテゴリ名も並び順も自分で決められる
- 買い物中はチェックを付けていき、最後に「買い物終了」でまとめて確定
- よく買うものが候補の上に出る
- JSON / CSV で書き出し・読み込み

## できないこと（意図的に持たない機能）

- **購入履歴を振り返る画面はない。** 「次に買うもの」のリストとして使う
- **数量を持たない。** 「牛乳2本」は表現できない
- **端末間で同期しない。** データは開いた端末のブラウザ内にだけ残る
- 価格管理、在庫管理はしない

なぜこれらを捨てたかは [DESIGN_NOTES.md](DESIGN_NOTES.md) に書いてある。

## 使い方

### 置く

`index.html` を1つ置くだけで動く。ビルドも外部ライブラリも要らない。
GitHub Pages でも、ローカルにファイルを置いてブラウザで開くのでもいい。

### iPhoneで使う

1. Safari で開く
2. 共有 → ホーム画面に追加
3. **以後はホーム画面のアイコンから開く**

### 基本の流れ

1. 上の入力欄に名前を入れて登録する（初回だけ）
2. 以降はタップでリストに出し入れする
3. 買い物中、カゴに入れたものをタップしてチェックを付ける
4. 会計後、下部の「買い物終了」を押す。チェック済みだけがリストから消える

チェックの付いていないものは残る。買えなかったものが翌日に持ち越される形になる。

## データについて（重要）

**データは開いた端末のブラウザ内（localStorage）にだけ保存される。**
サーバーには何も送信されない。作者を含め、誰も内容を見ることはできない。

その代わり、次の場合にデータは失われる。

- ブラウザの「Webサイトデータを削除」を実行したとき
- プライベートブラウズで開いたとき
- ブラウザがストレージを整理したとき
- 端末を変えたとき、ブラウザを変えたとき

**バックアップは自分で取る必要がある。** 設定画面の「JSONで書き出す」を使う。
書き出したファイルは「JSONを読み込む」で元に戻せる。

### iOSでの注意

**ホーム画面に追加したアプリと、Safariで開いた場合とで、データが別々になる。**
これはiOSの仕様。どちらか一方に決めて使うこと。

Safariで開いた場合は、画面上部にその旨が表示される。
リストが空に見えても、ホーム画面版のデータが消えたわけではない。
